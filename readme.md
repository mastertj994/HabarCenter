# ◈ HabarCenter

Профессиональный современный новостной портал с темной эстетикой, кастомной админ-панелью, встроенным умным WYSIWYG-редактором и полной адаптивностью.

## 🚀 О проекте
HabarCenter создан как удобная и быстрая платформа для публикации актуальных новостей, статей и обзоров. Проект не требует тяжелой серверной инфраструктуры и полностью автономен на стороне клиента.

## 🛠️ Технологии
* **HTML5 / CSS3** — структура и современный дизайн с кастомными градиентами и эффектами свечения.
* **JavaScript (ES6+)** — интерактивная логика, управление базой данных и продвинутый редактор статей.
* **localStorage** — локальное хранение данных и синхронизация публикаций.
* **Base64** — встроенная конвертация и сохранение изображений прямо в теле статей без внешних хостингов.

## ✨ Ключевые особенности
* **Умный админ-панель:** Защищенная панель управления контентом.
* **Продвинутый редактор:** Поддержка форматирования текста (жирный, курсив, цитаты), выбор цвета и размера шрифта, вставка ссылок.
* **Работа с изображениями:** Загрузка картинок с ПК или по URL, а также интерактивное изменение размера прямо в редакторе (25%, 50%, 75%, 100%).
* **Экспорт/Импорт базы:** Удобный перенос базы данных между локальной средой и продакшеном.
* **Кроссплатформенность:** Одинаково отлично смотрится на ПК, планшетах и мобильных телефонах.

## 📦 Развертывание
Проект оптимизирован для быстрого деплоя на хостингах статических сайтов, таких как **Vercel** или **GitHub Pages**.
